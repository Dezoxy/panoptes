# Portal

- **Owner** — AI Platform
- **Status** — Planned
- **Last reviewed** — 2026-09-21
- **Out of scope** — the developer documentation site (`docs-site/`); the CLI that does the
  same work from a terminal (`automation/`); and dashboards for the platform team, which
  live in `telemetry/`.

The self-service request and status surface for consumers: submit an onboarding request,
see where it is in the lifecycle, see current entitlements and quota, see spend against
budget, and request a change. It is a front end over the platform CLI and the policy
engine, not a second source of truth.

Nothing lands here until the things it would show exist and are stable. A portal over an
unfinished platform documents churn.

Arrives in **Phase 5**, the last phase.
